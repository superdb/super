# JavaScript

The [superdb-types library](https://github.com/superdb/zui/tree/main/packages/superdb-types)
provides support for the ADM from within
JavaScript as well as methods for communicating with a SuperDB database.

Because JavaScript's native type system is limited, superdb-types provides
implementations for each of the primitive types as well as
technique for interpreting and/or constructing arbitrary complex types.
